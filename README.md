Autonomous Line-Following and Obstacle-Avoiding Robot

Grade: 2.0

This project focused on the development of a fully autonomous mobile robot based on the ATmega328P (Arduino Uno). The robot is capable of navigating a predefined track independently while reacting to environmental inputs such as lines, colors, and obstacles.

Project Highlights

Team-based development covering system design, integration, and testing.

Implementation of a finite state machine (FSM) in C using Arduino libraries to manage robot behavior and decision-making.

Integration of line-following sensors with an L298N motor driver for reliable motion control based on track detection.

Speed and motion optimization to handle diverse track geometries, including sharp 90° turns, oval tracks, and figure-eight paths.

Use of the HC-SR04 ultrasonic sensor for real-time obstacle detection and distance evaluation.

Mechanical design and fabrication of 2D and 3D components using SolidWorks and Fusion 360, utilizing materials such as PLA and wood.

Calibration and use of the TCS3200 color sensor to identify specific colors and trigger actions such as parking maneuvers or route changes.

System modeling with SysML, based on a structured analysis of functional requirements and system behavior.

Recognition for implementing the highest number of color-detection-based features among project teams.

Additional documentation, design files, and test results are available in this repository.
